# 업무 도움말 포털 견본 — 누리금속(가상)

> **견본입니다.** 실무 경험을 바탕으로 가상 회사를 설정해 처음부터 새로 만든 포트폴리오입니다.
> 실제 회사나 ERP 제품과 관계없습니다.

**사이트:** https://yeonoc.github.io/nuri-help-portal-sample/

---

## 무엇을 만들었나

제조업 현장에서 ERP를 처음 도입하면 교육은 몇 차례뿐이고, 그 내용은 담당자 개인 메모나 구두 전달로만 이어지는 경우가 많습니다. 이 프로젝트는 그런 상황에서 발생하는 세 가지 문제를 다루는 사내 도움말 포털입니다.

| 문제 | 해결 방법 |
|---|---|
| 교육 후 지식이 흩어짐 | 모듈별 단계별 도움말 — 언제든 찾아볼 수 있음 |
| 설정 이유가 한 사람에게만 있음 | 관리자 화면에 설정값·결정 이유를 함께 보관 |
| ERP가 지원하지 않는 관리 업무 | ERP는 주문 단위로만 관리함. 총량계약은 관리번호로 주문을 묶어 계약별 나간 양·남은 양을, 임가공은 받은 원료 × 회수율로 업체별 남은 지급 의무량을 보여 주는 도구 |

## 설계 판단과 이유

### 1. 콘텐츠는 JSON, 화면은 HTML 셸로 분리

도움말 내용을 `data/*.json`에 두고, HTML 파일은 구조만 담당합니다.
검색(`js/search.js`)이 같은 JSON을 읽으므로 콘텐츠를 한 곳에서만 관리합니다.
새 단계나 FAQ를 추가할 때 JSON만 고치면 됩니다.

### 2. 직원용·관리자용 화면 분리

직원 화면에는 "어떻게 쓰나"만, 설정값과 결정 이유는 관리자 화면에만 둡니다.
사내망 정적 사이트라 완전한 접근 제한은 불가능하지만, 화면을 나눠 혼동을 줄이고
관리자 화면에는 항상 안내 띠를 표시합니다. 가짜 비밀번호는 만들지 않습니다.

### 3. 빌드 도구·CDN·외부 글꼴 없음

사내망에서 인터넷 없이도 동작해야 합니다. 모든 CSS·JS는 로컬 파일입니다.
Pretendard(OFL 라이선스)가 로컬에 없으면 시스템 글꼴로 자동 대체됩니다.

### 4. 대조 도구: 원본 불변, 쌓이기만 하는 자료, 완전히 지우지 않기

업로드한 CSV는 브라우저에서만 읽고 계산하며, 올린 파일을 수정하지 않습니다. ERP 자료는 올릴 때마다 쌓이고
같은 주문번호·입고번호만 새 값으로 바뀝니다. 지운 계약은 "삭제된 계약"에서 되살릴 수 있고, 회수율을 고치면
전·후 값을 이력으로 남깁니다. 초과·미출고처럼 차량 단위 주문과 실제 무게 출고 때문에 생기는 차이는
오류가 아니라 "참고"로 표시합니다.

### 5. ERP를 바꾸지 않고 묶는 규칙 하나: 관리번호와 품목코드

총량계약은 주문의 관리번호에 고객 PO 번호를 계약과 똑같이 적는 규칙 하나로 주문을 계약에 묶습니다.
임가공은 품목코드 하나를 한 업체에만 두는 규칙(중복은 막음)으로, 같은 출고 파일에서 임가공 제품 행을
자동으로 나눕니다. 임가공 지급 의무량은 받은 원료 × 그해 회수율이고, 나간 제품은 업체별로 가장 오래된 달부터
차감해 "지금 몇 월분을 갚는 중인지" 보여 줍니다. CSV 읽기·ERP 자료 저장(`js/erp-data.js`)과 계산
(`js/contract-calc.js`, `js/subcontract-calc.js`)을 화면 코드와 나눠, 계산만 Node로 견본에 대해 검증할 수 있게 했습니다.

### 6. 모든 색은 CSS 변수(토큰)로만, 다크 모드는 화면에만

코드에 색 값을 직접 쓰지 않습니다. 라이트·다크 모드 전환이 `:root`의 변수 값만
바꾸면 됩니다. 다크 색은 화면에만 적용해, 다크 모드에서 인쇄해도 흰 종이에 진한
글자로 나옵니다. 새 색을 추가할 때 대비(WCAG AA 4.5:1 이상)를 계산해 `design.md`에
기록합니다.

### 7. 현장 모드(글자 크게)와 자동 검사

공용 PC나 휴대폰에서 짧게 보고 바로 작업하는 현장 직원을 위해 본문 18px·표 17px·버튼 48px으로
전환하는 스위치를 헤더에 둡니다. 선택은 `localStorage`에 저장하고, 실패해도 기본값으로
동작합니다.

`node tools/check.mjs`가 금지 단어·JSON 문법·내부 링크·외부 URL을 한 번에 검사합니다.
가상 데이터 규칙 위반을 코드 리뷰 없이도 잡을 수 있고, 커밋 전 습관적으로 돌릴 수 있습니다.

## 실무 버전과 다른 점

실무에서는 사내 웹서버·서버 처리기·서버 파일 저장·백업이 붙지만,
이 견본은 GitHub Pages 정적 사이트입니다.

| 항목 | 실무 | 이 견본 |
|---|---|---|
| 서버 | 사내 웹서버 | 없음 (GitHub Pages) |
| 콘텐츠 저장 | 서버 파일·DB | JSON 파일 (저장소에 함께) |
| 접근 제한 | 사내망 IP 제한 또는 로그인 | 없음 (URL을 알면 접근 가능) |
| CSV 처리 | 서버에서 처리, 결과 저장 | 브라우저에서 처리, 저장 없음 |
| 도구 설정·계약·ERP 자료 | 서버에 저장, 담당자끼리 공유 | 이 브라우저의 `localStorage`, 사람·PC마다 따로 |
| 계약 등록 | 고객 PO 문서에서 자동으로 채움 | 계약 CSV 올리기 (문서 읽기는 외부 라이브러리가 필요해 제외) |
| 변경 기록·동시 수정 | 고치기 전·후, 이름, PC 정보를 남기고 동시 수정을 막음 | 회수율 변경 이력과 계약 되살리기만 (브라우저 안에서) |
| 보관 | 자동 백업 + 정기적으로 엑셀 내려받아 보관 | 없음 (브라우저 데이터) |
| 백업 | 서버 자동 백업 | 저장소 커밋 이력 |

## 알려진 한계

- **관리자 화면 접근 제한 없음.** 가짜 비밀번호를 만들지 않는 것이 의도된 선택입니다.
- **JavaScript 필수.** JS를 꺼도 페이지 구조는 보이지만, 도움말 콘텐츠는 `<noscript>` 안내문만 표시됩니다.
- **검색 범위.** 4개 모듈 도움말·FAQ·용어집을 함께 검색합니다. 대조 도구와 관리자 화면의 내용은 검색하지 않습니다.
- **도구 데이터는 이 브라우저에만 남습니다.** 다른 PC나 다른 사람과 공유되지 않고, 브라우저 데이터를 지우면 사라집니다.
- **ERP 자료는 쌓이기만 합니다.** 잘못 올린 자료를 한 건씩 지우는 기능은 없습니다. "모두 지우기" 후 다시 올려야 합니다.
- **CSV는 UTF-8만 읽습니다.** 다른 인코딩으로 저장한 CSV는 한글이 깨집니다. 저장할 때 UTF-8을 고르세요.
- **인쇄 쪽 아래 문구는 Chrome·Edge 기준입니다.** 쪽 여백 문구(`@page` 여백 상자)를 지원하지 않는 브라우저에서는 쪽 아래 문구가 나오지 않습니다.
- **계약 정산은 오늘 날짜 기준입니다.** 납품 마지막 달이 지난 계약이 정산 탭에 나오므로, 견본도 시간이 지나면 정산 대상이 늘어납니다.
